# Sistema de Gestión de Citas Médicas

## Instalación y configuración
1. Clonar el repositorio.
2. Asegurar tener instalado el JDK 11.
3. Abrir el proyecto en el entorno de desarrollo IntelliJ IDEA.

## Uso del programa
El sistema permite registrar pacientes, doctores y agendar citas médicas utilizando conceptos de Programación Orientada a Objetos mediante un menú interactivo en consola.
